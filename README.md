# WordPress Modernization on Azure AKS

## Objective
Migrate an existing Azure VM-based WordPress application to AKS
and measure the impact on performance, deployment, reliability, and cost.

## Planned Architecture
- WordPress container images stored in Azure Container Registry
- Azure Kubernetes Service running WordPress
- Helm for Kubernetes deployment
- Existing Azure MySQL Flexible Server retained
- Azure Files for shared WordPress uploads
- Azure Key Vault for secrets
- GitHub Actions with OIDC for automated deployment
- Terraform for infrastructure
- AI-assisted runbook generator

## Project Status
Repository initialized. Implementation has not started.
